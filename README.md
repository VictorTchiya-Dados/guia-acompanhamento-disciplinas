# Guia de Acompanhamento de Disciplinas — Excel

## Sobre o projeto

Este projeto foi desenvolvido como um exercício prático de aprendizagem em Excel, com o objetivo de criar uma ferramenta visual para acompanhar o andamento de disciplinas.

A proposta é organizar as informações em uma planilha e facilitar a identificação das etapas concluídas, em andamento e ainda não iniciadas, utilizando recursos de validação, fórmulas, gráficos e formatação condicional.

O projeto faz parte da minha jornada de desenvolvimento de habilidades em Excel e análise de dados.

**Link arquivo:** 
[**Guia_Acomp_Disciplinas.xlsx**](https://github.com/user-attachments/files/33851009/Guia_Acomp_Disciplinas.xlsx)


## Objetivos

- Organizar o acompanhamento de disciplinas.
- Padronizar o preenchimento dos status.
- Automatizar a contagem das etapas.
- Facilitar a visualização do progresso por meio de gráficos.
- Explorar recursos do Excel aplicados a uma situação prática.

## Ferramentas e recursos utilizados

- **Validação de Dados:** padronização das opções de preenchimento.
- **Função CONT.SE:** contagem das disciplinas conforme seus respectivos status.
- **Gráfico de colunas 100% empilhadas:** representação visual da distribuição dos status.
- **Formatação Condicional:** aplicação de recursos visuais de acordo com os valores registrados.
- **Organização de layout:** estruturação visual da planilha para facilitar a navegação e a leitura.

## Lógica de acompanhamento

A ferramenta utiliza uma classificação numérica para representar o andamento das disciplinas:

| Valor | Status |
|---|---|
| 0 | Não iniciada |
| 1 | Em andamento |
| 2 | Concluída |

A função CONT.SE permite contabilizar os registros de cada categoria, enquanto o gráfico apresenta visualmente a distribuição dos status.

## Possibilidades de aplicação

A lógica utilizada pode ser adaptada para outros contextos que envolvam acompanhamento de etapas, como:

- Gestão de tarefas e atividades.
- Acompanhamento de projetos.
- Controle de cronogramas.
- Monitoramento de etapas de execução.
- Organização de estudos e metas de aprendizagem.

## Aprendizados

Este exercício contribuiu para a prática de recursos do Excel, especialmente na organização de informações, padronização de dados, utilização de fórmulas e representação visual de indicadores.

Mais do que desenvolver uma planilha, a proposta foi experimentar como recursos simples podem ser combinados para construir uma ferramenta funcional.

## Próximos passos
